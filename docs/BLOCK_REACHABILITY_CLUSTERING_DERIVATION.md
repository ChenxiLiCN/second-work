## 1. 本轮变化及范围

旧候选只明确了逐集合计数，未解决批量候选。这里把两个问题分开：

1. 原始关系索引能否证明查询关系在 X×Y 上全部成立或全部不成立？
2. 当一块已经被证明时，怎样不展开块内所有边，仍完成核心、簇与角色处理？

新变化不是寻找共同的单个见证，而是允许不同顶点通过不同见证完成整块覆盖。
下面的 Reach 规则适用于显式关系序列，并不要求对称半路径。无序顶点对和并查集的聚类执行证明针对当前项目采用的无向、非独立 HINSCAN 投影语义；它不是任意有向聚类模型的证明。所有原问题合法输入的适配仍是交付门槛，不能为提高加速比擅自限制查询。

语义核对来源：[HINSCAN 定义 3.5—3.11](https://lai.me/files/HINSCAN-final.pdf)，以及当前 src/scan/PscanOnFli.cpp 中的非核心归属和角色处理。
自身计入闭邻域与 μ；非核心可属于多个簇；仅无簇归属顶点根据元路径邻居接触的簇判断 hub/outlier。

## 2. 离线的具体候选：原始关系二维分区摘要

一维邻接集合树可以作为精确运算内核，但没有自动提供跨源顶点的覆盖信息。这里明确提出一个需单独评估的结构扩展，而不是声称原结构已具备这些摘要。

对每个原始关系方向，将原始边看作 (源类型局部 ID, 目标类型局部 ID) 点集。两个轴采用固定二分域，交替分裂仍可分裂的轴；删除空孩子、压缩单支路径，保留域/深度描述。
不按元路径建树，不枚举所有矩形，不加入可调分区数。正反方向可共用点集视图，也可各存一份，但字节数必须如实计入。

每个已有非空结点 X×Y 保存常数个字段：

- 源域、目标域、孩子/压缩路径；
- 原始边数；
- 在该矩形内有邻居的不同源点数、不同目标点数；
- 行度最小值/最大值、列度最小值/最大值，最小值包含域内零度点。

由这些字段可以直接判断：

    EMPTY: 边数为 0（通常由缺省空孩子表达）
    FULL: 边数 = |X|*|Y|
    ROW_COVER: 每个 x∈X 在 Y 中至少有一个邻居
    COL_COVER: 每个 y∈Y 在 X 中至少有一个前驱

只对索引中确实存在的结点/可证明的空域进行直接读取。任意查询矩形若需要合并多个结点，必须计入访问与去重成本，不能视为 O(1) 查询。

### 存储和构建成本

一个关系有 m_r 个去重边点时，未做 FULL 合并的压缩二叉点树最多 m_r 个叶、m_r−1 个分支。每个结点保存常数个机器字，因此双向所有关系合计 O(m+n+schema) 个机器字。类型分区和稀疏入口另计，原始图若仍保留也要计入完整索引。

这个界依赖于压缩单支路径和不额外保存所有行覆盖集合。若存每个结点的完整源点/目标点清单，就不能直接沿用该线性界。

一种有限的构建方法是在各结点对应的原始点段上统计行/列次数，保存标量后释放临时次数表，再递归子结点。设固定划分最大深度 H=O(log n_source+log n_target)，逐结点排序计数的保守上界为 O(m H log(m+1))，可通过更好的构建降低；这不是已测的构建效率。临时表不应在所有层同时保留。

线性字数不等于体积小：多个 64 位计数、域和孩子句柄的常数可能较大。本轮没有给出实际 MB 数或索引/数据比例。

## 3. 能穿过不同见证的三条安全规则

记 Q=A·B，X 为起点块、Z 为中间类型的一个非空块、Y 为终点块。
Full(Q,X,Y) 表示所有 x∈X、y∈Y 都存在对应路径。
Cover(Q,X,Y) 表示每个 x∈X 至少能到达 Y 中一个点；CoCover 是每个 y 至少有一个来自 X 的前驱。

### 规则一：逐行有路 + 后段全通

    Cover(A,X,Z) AND Full(B,Z,Y) => Full(Q,X,Y)

证明：对每个 x，选择其各自能到达的 z_x；该 z_x 可以到达每个 y。不同 x 不必选择相同 z。

### 规则二：前段全通 + 逐列有前驱

    Full(A,X,Z) AND CoCover(B,Z,Y) => Full(Q,X,Y)

证明：对每个 y，选择其各自的前驱 z_y；每个 x 都能到达这个 z_y。

同时有 Cover(A,X,Z) AND Cover(B,Z,Y) => Cover(Q,X,Y)，以及相应的反向规则。这些是充分条件，不是必要条件。

### 规则三：中间域内的计数交叠

若每个 x 经 A 在 Z 中至少到达 a 个不同顶点，每个 y 经 B 的反向在 Z 中至少有 b 个不同前驱，则：

    a+b > |Z| => Full(Q,X,Y)

证明：两个 Z 的子集大小和超过 |Z|，必相交；选交点拼接路径即可。这里必须计不同顶点，而非路径条数。
当 A、B 是原始关系、矩形恰好对应已存结点时，a、b 可直接从离线的最小行度/最小列度读取。多步查询的 a、b 并未离线保存，需要递推得到安全界或返回未知，不能免费假定已知。

### 空块规则

如果一组互斥 Z_i 覆盖完整中间类型，且每个 i 都满足 Empty(A,X,Z_i) 或 Empty(B,Z_i,Y)，那么 Empty(Q,X,Y) 成立。
必须覆盖全部可能中间顶点；只检查一个没有通路的 Z 不能证明不存在其他通路。

所有无法证明的情况返回 UNKNOWN，不据此判假。一般元路径重复类型也必须保留位置/后缀信息。

## 4. 上一轮反例现在怎样处理

k 个用户各有一个不同评论，所有评论属于同一商家 b，且例子中无其他用户、评论或商家：

    ui -- ri -- b
    查询 U-R-B-R-U

离线根摘要可知 U→R 逐行有路，R→{b} 全通，{b}→R 全通，R→U 逐列有前驱。
规则一得到 U→{b} 全通，规则二得到 {b}→U 全通，拼接得到 U×U 全通。
不需要用户第一跳邻居相同，也不需要列出 k(k−1)/2 条投影边。

于是每个用户闭邻域为全部 k 个用户，度数 k、任意用户对相似度 1。对合法 ε 和 μ≤k，输出一个全核心簇；μ>k 时没有核心，全部无簇归属且为 outlier。
本例中证书可以由常数个根摘要组合，最终逐顶点输出需 O(k) 工作；这是避免二次展开的构造性例子，不是实际运行时间，也不是对所有图的界。

必须强调：项目已有 RegionCompletion.cpp 会对某些整区/大 posting 提前完成。这个例子只验证新规则能工作，不能用它宣称相对现有方案的新贡献或十倍收益。新候选若有价值，应体现为在生成半路径因子之前完成判定，以及处理现有规则不能完成的区域。

## 5. 相似度块判定：不能把全通当作全部相似

记 E(v)=Reach_P(v)∪{v}。先获得精确度数 d_v，或保守上下界。精确度数可以只返回标量，不保存完整 E(v)。参考执行使用精确度数数组及其区间 min/max 树，O(n) 标量空间；获得度数的全部计算时间仍计入在线。

对源块 X、Y，取目标域的互斥完整划分 W_j。针对闭邻域关系判定 Full_E/Empty_E，自身作为虚拟恒等关系并入，不能漏掉孤立点。

    L = sum |W_j|，其中 Full_E(X,W_j) 且 Full_E(Y,W_j)
    U = sum |W_j|，其中两侧均未被证明 Empty_E

对所有 x∈X,y∈Y 都有 L≤|E(x)∩E(y)|≤U。未知块可细分以收紧界；细分和 Reach 递推的访问不是免费操作。

设块内精确度数的最小/最大值为 dXmin,dXmax,dYmin,dYmax：

    先证明 X×Y 上元路径邻接全部成立
    L² ≥ ε²*dXmax*dYmax => 全部相似
    U² < ε²*dXmin*dYmin => 全部不相似

若邻接块 EMPTY，可直接跳过而不求相似度。若邻接或相似度仍 UNKNOWN，继续划分源/目标块；到单点对时调用精确邻接/交集判断。
实际代码应沿用现有阈值的精确比较，处理整数溢出和相等边界，不引入浮点近似判错。

## 6. 避免重计：划分顶点对空间，不按见证重复分组

对当前无向投影，只处理每个无序不同顶点对一次。固定一维顶点树上的三角区域递归为：

    Triangle(I):
        若整个 I 是全部相似的闭邻接块，输出 Clique(I)
        否则若 I 为单点，返回（自身单独计入）
        否则处理 Triangle(I_left), Rectangle(I_left,I_right), Triangle(I_right)

    Rectangle(X,Y):  # X,Y 不交
        邻接 EMPTY 或相似度全否 => 丢弃
        邻接全真且相似度全真 => 输出 SimilarBlock(X,Y)
        单点对 => 精确处理
        否则按固定规则二分仍可分的较大端点域，处理不交的孩子矩形

终止输出矩形在顶点对空间上互不重叠。不同见证即使证明同一块，也只给这个块贴一次标签，不产生额外的边或重复计数。
最坏情况下会退化到所有顶点对；这套遍历本身不保证比候选邻居驱动的 pSCAN 快。

## 7. 块怎样接入完整聚类

下面给出语义等价的参考执行，用于证明“无需展开块内边也能输出正确结果”。它不是已实现的 pSCAN 优化，也不宣称与源码有相同调用顺序。
实际接入必须保持现有 pSCAN 的相似/有效邻居计数、核心判断、核心连接、非核心归属语义；若采用其他调度，须单独验证其等价性与代价。

### 7.1 核心计数

相似邻居数初始化为 1，计自身。
对 SimilarBlock(X,Y)，给 X 每个顶点增加 |Y|，给 Y 每个顶点增加 |X|。因为域为连续 ID 区间，可对差分数组做常数次更新，最后前缀累加。
对 Clique(I)，给 I 每个点增加 |I|−1。单点精确相似边等同长度 1 区间。
由于顶点对分区不重叠，计数与逐条相似边累加完全一致，达到 μ 的点就是核心。
这里的常数次更新只指已确认块的计数动作，不包括确认该块的成本。

### 7.2 核心连通

对相似矩形取 C_X=X 中核心点、C_Y=Y 中核心点：

- 两侧均非空：取 x0∈C_X、y0∈C_Y，将每个 C_X 点连接 y0，每个 C_Y 点连接 x0。这些都是已确认存在的相似边，至多 |C_X|+|C_Y|−1 次必要连接便保留该完全二部子图的连通性。
- 任一侧为空：不做核心合并。不能只因另一侧有多个核心就将它们合并。
- 核心 Clique 用一个核心代表连接其余核心。

单块由二次边数降为线性成员访问；跨多个块的核心访问可能重复，须计入总成本，不能直接声称全查询 O(n)。

### 7.3 非核心归属

对 SimilarBlock(X,Y)，将 C_X 的不同最终核心簇编号加入 Y 中每个非核心顶点的归属，反向亦然。不能只取一个代表簇：当 Y 没有核心时，X 中的核心可能来自多个互不连接的簇。
最终逐顶点去重。生成的归属候选可能在多个块重复，时间须按实际生成次数计，不只按去重后输出大小计。
任何有归属的非核心点都是 border，多簇归属不自动变成 hub。

### 7.4 hub/outlier

此阶段用的是原元路径邻接块，不是仅用相似块。相似度不达标的邻居仍可能决定 hub。
簇固定后，对每个目标分区保存其所有成员归属中的至多两个不同簇编号；可用“两项最小不同编号”的可合并摘要，包含 core 和 border。
若 X×Y 被证明全部邻接，则 Y 的摘要可以贡献给 X 中无归属的顶点；混合块继续分裂。只有无归属顶点接触至少两个簇才是 hub，其余为 outlier。
摘要树只需 O(n) 个常数大小结点。产生这些摘要须读取实际簇归属；不能忽略多簇输出的成本。

## 8. 完整参考伪代码与空间选择

    I = 离线原始关系分区索引  # 输入仅 G,schema

    Query(I,P,epsilon,mu):
        以惰性集合计数取得闭度数标量，建立区间度数 min/max
        用互斥顶点对遍历流式生成相似块，区间累计相似邻居数
        由 mu 得到核心集合
        在相似块上执行核心代表连接，取得核心簇
        在相似块上执行非核心归属并去重
        在元路径邻接块上执行无归属顶点的角色判定
        返回簇和角色

这段伪代码需要解释如何重新访问块，不能隐去存储：

- 保存全部已解析块：若细分到单边，仍可能成为查询投影/相似图的另一种存储。不能不加限制地采用。
- 不保存块而按阶段重放：可维持流式块空间，但增加判定计算。可以作为正确性参考实现，不应直接作为时间优先的生产方案。
- 与 pSCAN 状态联动、按已知核心及时消费块：可减少重放机会，但保留哪些块、何时拆分以及峰值状态量仍需明确设计。

本轮没有借四遍重放宣称解决性能，也不增加用户缓存预算参数。原始索引线性与查询峰值内存受控是两项独立义务。

## 9. 摘要不足的反例

令 X={x1,x2}, Z={z1,z2,z3,z4}, Y={y1,y2}。
A 的两行分别是 {z1,z2} 和 {z3,z4}。

B 的两种情况：

    B_good: y1 前驱 {z1,z3}, y2 前驱 {z2,z4}
    B_bad:  y1 前驱 {z1,z2}, y2 前驱 {z3,z4}

两种 B 的总边数、每行度数、每列度数、行/列覆盖数均相同；A 也相同。
但是 A·B_good 在 X×Y 上全部成立，A·B_bad 只有 x1→y1、x2→y2。
这里 a=b=2、|Z|=4，不满足严格大于的交叠条件，返回 UNKNOWN 是必要的。

因此，块级计数摘要不能普遍解决多步可达，必须在一些情形读取更细结构。完整原始索引能区分它们，但区分的访问成本无法由几个计数消除。
这不否定规则三的正确性，也不是任何索引都不可能快速的证明。

## 10. 性能判定与和现有方法的区别

设 V 是包括失败尝试、细分、重放在内的实际状态访问；A 是原始关系条目/结点访问，K 是表达式键和去重工作，B 为确认块数，F 为精确回退工作，J 为核心成员访问，O_try 为实际归属生成及角色处理工作。

    T_new = T_degree + T_block(V,A,K) + O(n+B) + O(J*alpha(n)) + F + O_try

这里不把一个大操作数状态当作 O(1)，也不把离线索引读取、原始图读取和写出时间混入纯计算时间。
只有上述总和小于同口径 HINSCAN 完整计算时间的十分之一，才实现目标。没有实际数据支持时不给秒数或十倍承诺。

相对旧共享前缀/包含方案，真正不同的可检验点是：原始二维分区的行/列覆盖与交叠规则，可以证明使用不同中间点的整块可达，并在生成完整半路径因子之前消费结论。
如果实际仍需生成同一套因子、扫描同样多 posting 才能找到块，则没有获得这一优势；不能仅因名称改变就认定新结构有效。

## 12. 后续推导：即时确认核心与处理块

本节解决第 8 节中的一部分调度缺口，不修改离线索引。以下 μ 均包含自身，合法 μ≥2；n 是本次查询目标类型顶点数。

核心状态具有单调性：一旦已经确认的不同相似邻居（含自身）达到 μ，后续发现更多边不会让该顶点失去核心身份。利用这一点，不必等全部块处理完才确定所有核心。

维护三项查询期状态：

1. L(v)：已经确认的相似邻居数，未确认核心者精确维护，初始为 1。达到 μ 后核心标记永久成立。
2. 核心并查集：只连接已经确认是核心的顶点，只使用已经确认的相似边。
3. 未决关系 D：已经确认相似、但至少一个端点尚未确认核心的边记录。记录端点而非相似度；不放进离线索引。两端都已被安全判为最终非核心的记录可立即丢弃。

关键纪律：先批量更新 L 并确认所有跨过阈值的核心，再决定当前块有哪些关系需要暂存；不能先把整个块展开存下，再处理核心变化。

### 相似矩形的处理顺序

对互斥顶点对分区产生的 SimilarBlock(X,Y)：

    1. 对尚未确认核心的 X 顶点，L 增加 |Y|；反向增加 |X|。
    2. 将全部 L>=mu 的新核心标出；只发生一次身份转换。
    3. 检查新核心以前的未决记录：若另一端也已是核心，执行真实边合并并移除记录；否则保留为未来归属或连接依据。
    4. 对当前块里的核心子集 C_X,C_Y 执行第 7.2 节的代表边连接。
    5. 只登记当前块剩下的、至少一端非核心的相似对；双方均已最终判非核心的对不登记。

Clique(I) 使用增加 |I|−1 的同类步骤。每个无序顶点对仍必须只计入一次，复用证书不等于再次累加。
未决记录的另一端后来成为核心时，应处理原记录，而非创建第二份副本。可用双向端点链和共享记录标识，保证两端的触发不会重复创建或重复计数。

已确认不相似/不相邻的终止块不需要为上述连接与归属留下逐对记录。它们是否能用于降低 pSCAN 的有效邻居上界，必须按真实相邻数更新；不能对部分相邻块直接减去整个 |Y|。

## 13. 未决关系总量的上界

命题：在上述一次性计数、即时核心转换和记录不重建的条件下，整个查询累计创建的未决边记录数至多 n*(μ−2)；峰值活跃记录数也不超过此值。端点链指针只增加常数倍空间。

证明：

- 一条边仅在本批次核心转换之后仍有非核心端点时才会创建未决记录，将创建成本记在其中一个这样的端点 v 上。
- 此时 v 的非自身已确认相似邻居数为 L(v)−1≤μ−2；否则 v 应已转换为核心。
- L(v) 只增不减，每条相似边只计一次。因此 v 在整个尚非核心期间，最多承担当中的 μ−2 条不同边的创建成本。
- 一旦 v 转为核心，再也不给它计新的创建成本；若始终非核心，限制也一直成立。对所有 v 求和即得上界。

这个界不仅是某一时刻的快照，还是累计创建数的界。每条记录最多经历两个端点的核心转换触发及一次最终处理，因而记录处理量也是 O(nμ)，在使用 O(1) 链接删除等相应数据结构的前提下成立。

批量大块不会破坏该界：若 X 有至少 μ−1 个顶点，当前块确认后 Y 中所有顶点立即成为核心；这样的 Y 点不会再承担当前块的未决记录成本。只展开需要暂存的剩余部分，不先展开 C_X×C_Y。

### 必须说明的边界

- μ=2 时，上界为 0：任一确认相似的非自身边会立即让双方成为核心。
- 固定较小 μ 时，未决记录具有线性数量上界；不需要用户再设置一个缓存阈值。
- μ 随 n 增长时，O(nμ) 仍可能达到二次规模。这不是对所有合法 μ 的小空间证明，甚至可能暂存很大比例的相似关系；不能无条件称为严格免物化。
- μ>n 时可以直接判无核心，全部无簇归属且为 outlier，无须建立未决关系。但这一特例不能解决所有较大 μ 的情况。
- 界只覆盖调度器的未决关系，不覆盖 Reach 展开、度数计算、表达式键、找块前沿、原始索引和输出等其他内存。

因此本节是一项有用的参数化界，不是已解决全部工作内存问题。不通过限制用户的 μ 取值掩盖该边界。

## 14. 为什么它能保留最终的簇和边界归属

设 S_t 为已处理前缀内确认的相似边集合，K_t 为已经确认的核心集合。维护不变量：

1. 每个尚非核心 v 的 L(v)=1+deg_{S_t}(v)，其中当前批量计数必须完成后才进入稳定状态。
2. 核心并查集与 S_t 在 K_t 上的诱导子图具有相同连通分量。
3. S_t 中至少一端尚非核心、且仍可能用于连接/归属的边，都有未决记录；无须留存已经被核心代表连接充分处理的核心—核心边。

新核心的旧相似边此前必有一个尚非核心端点，因此仍保留在 D 中；处理这些记录即可补齐旧边中新出现的核心—核心连接。当前块的新核心—核心连接由真实代表边保留。并查集从不通过非核心顶点连接两个核心分量。

当全部必要的未决候选处理完、剩余顶点被确定为非核心后：

- D 中非核心—非核心记录可丢弃；
- D 中核心—非核心记录，将核心的最终并查集编号加入另一端归属并去重；
- 核心—核心关系已经处理完，无须重放相似块。

由此，核心判定、核心连接、非核心归属可以在一次相似关系处理过程中衔接，不必为这三项工作再做三遍相似度计算。
这不意味着整次查询没有重复工作：不同块的 Reach 子问题仍可能重复，角色阶段也仍可能需要访问原元路径邻接。

### 一个手算时序

考虑投影图的边为 ab,bc,ac,ap,cq，取 ε=0.5、μ=4。闭度数分别为 d(a)=d(c)=4，d(b)=3，d(p)=d(q)=2；这五条边全部满足相似度条件。

先处理三角形 abc：三点 L 都为 3，暂时均未确认核心，三条关系保留。
再处理 ap：a 的 L 达到 4，成为核心；c 尚非核心，ac 不能丢弃。
最后处理 cq：c 成为核心，从保留的 ac 将 a、c 连接。b、p、q 最后都是这个簇的边界点。

若之前只给未知顶点保存一棵普通生成树 ab,bc，而丢弃 ac，则最终 a、c 之间的相似核心连接会丢失；不能通过非核心 b 代替。这说明“把所有未决关系先压成一棵森林”不是安全替代。
这是手工验证，不是已经运行的自动化测试。该普通投影例子也可用每条边一个独立中间见证的两跳 HIN 表达。

## 15. 与 pSCAN 的具体接口注意事项

当前 PscanOnFli.cpp 使用不含自身的计数与内部 mu_，外部问题参数另做转换。本节使用含自身表示，只是等价记法；接入时必须统一，不能重复加自身。

当前 push_core_if_new 使用计数恰好等于内部阈值的检测，适用于既有逐次增量。块更新可能一次跨过阈值，必须检测“此前未核心且更新后达到或超过”，不能原样搬用相等判断。此处只指出未来接入义务，没有修改代码。

即时批处理不能继续只用最后一次前缀和的差分数组。可用维护未核心顶点最小阈值缺口的区间树：区间加计数，提取所有缺口非正的顶点并使其退出待确认集合。B 个区间事件与最多 n 次身份转换的调度费用可做到 O((B+n)log n)，O(n) 结点空间。
已核心顶点无需继续保存用于核心资格的精确相似计数，但已有代表连接和未来边界归属仍必须处理。

本节证明的是等价状态更新方式，不是声称当前实现已经具有这种机制，也不是完全复制源码执行顺序。现有 pSCAN 的有效邻居剪枝、边状态复用、单次计数和核心连通检查均需在实际适配时核对。

## 16. 核心状态还能反过来减少找块工作

安全跳过条件：如果 X∪Y 中全部顶点均已确认核心，且均属于同一个已确认核心连通分量，那么 X×Y 上剩余未检查的相似关系不再影响任何输出。

理由：这些顶点的核心身份已确定；它们之间再有相似边也只会在同一核心分量内部增加边；也不涉及非核心归属。故可在进行该块的元路径展开与相似度证明之前跳过。

不能把条件放松为“每块各有一个核心”“原始图同一连通分量”或“存在公共非核心邻居”。这些都不足以安全跳过。

固定顶点分区结点可以保存已经证明的“全核心且同一分量”状态与一个核心代表。并查集只合并不拆分，因此正面证明永久有效，代表取当前 find 值即可；反面结果可能在后续合并后失效，不能永久缓存。
未得到正面证明的结点，按需核查孩子及核心状态，其访问成本必须计入。不能因为保存了代表就假定任意区间同分量检测 O(1)。

这是 pSCAN 已有同分量跳过思想的块级提前应用，而非声称该思想本身新颖。潜在收益是把检查移到昂贵的路径组合之前；其覆盖率和检查成本仍未验证。

## 17. 修正后的工作量与剩余瓶颈

设 Q_create 为累计未决记录数，J 为核心代表连接所访问的核心成员数，B 为块事件数，则在本节条件下：

    Q_create <= n*(mu-2)
    T_online = T_degree + T_find_blocks + T_exact_fallback
               + O((B+n)log n)
               + O((J+Q_create)*alpha(n))
               + T_membership_dedup + T_roles

并查集费用包含未决记录的最终 find 等操作；最终归属去重另计，不能免费。
这里减少的是相似块为了不同聚类阶段而被强制重放，以及已经归入同一核心分量区域的后续判断；没有证明 T_degree 或 T_find_blocks 足够小，也没有证明 J 对所有图接近线性。

生产方案仍不能直接采用对所有顶点对的无条件细分遍历。若索引对空块/全通块证明弱，它会访问大量原 pSCAN 不需要检查的非邻居对；即时调度不能补救这个损失。

当前更精确的判断是：小 μ 情况下，核心身份依赖造成的保存/重放矛盾有了一个可执行、可证明的处理方案；主要未解项转为如何低成本产生块、避免非邻居对搜索，以及如何控制较大 μ 和 Reach 中间状态的规模。
