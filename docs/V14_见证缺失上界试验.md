# V14：见证缺失上界试验

日期：2026-09-07。试验入口为 `bri_query_witness_exclusion`。离线 BRI、在线元路径/ε/μ、pSCAN 的聚类定义及簇/角色输出均不变；默认入口仍保留 V11，没有自动切换。

结论：Yelp 本轮三次中位数由 V13 的 24.58 s 降至 22.18 s，时间减少约 9.8%，相对完整 HINSCAN 复现约 5.67 倍。Movies、IMDB 中位数略慢且区间重叠，没有证实收益。本轮只算局部小幅改进，不是普遍升级或数量级突破。

## 1. 本轮两条尝试

先尝试将见证倒排按需转换成稀疏或稠密位图，保留量有固定上限，压缩不合适则保留列表。Yelp 的首轮结果为 V13 24.255 s、位图试验 24.918 s；实际保留的位图字节数和位图调用数都为 0。本轮选择规则按表示大小判断，而 Yelp 倒排的顶点编号分散，没有找到可压缩的候选。因此这次试验**没有验证出位图提速**，也不能据此断言所有位图策略都无效。

位图路径作为消融入口 `bri_query_witness_bitmaps` 保留，不是最终 V14 采用的优化；其初次二进制为 `experiments/v14/bri_query_bitmap_pilot.exe`，日志在 `experiments/v14/pilot/`。它可使用额外最多 32 MiB 查询内位图保留空间（另有元数据及构建临时空间），不是持久离线索引。

随后实现**单个见证集合的缺失上界**，使一部分不相似判定不必扫描候选的全部见证集合。首轮 Yelp 为 V13 24.211 s、新上界 22.384 s，簇和角色一致。最终重复测量见下一节。

## 3. 新上界及正确性

令 N[u]、N[v] 为闭邻域，w 是候选 v 的见证点，S(w) 是其倒排集合。因为 `S(w) subset N[v]`，有：

`S(w) minus N[u] subset N[v] minus N[u]`。

已有 V13 按需精确计数 `c(u,w) = |N[u] intersect S(w)|`。令 `missing(w) = |S(w)| - c(u,w)`，则：

`|N[u] intersect N[v]| <= min(d(u), d(v) - missing(w))`。

若这个上界已小于当前 ε 对应的精确整数阈值，可立即判定不相似，无需再遍历 v 的其余见证集合。只使用**单个集合中的不同缺失顶点**，不把多个重叠集合的缺失数相加，避免重复扣减。

该上界不满足拒绝条件时，仍依次使用 V13 的最大交集下界、交集计数求和上界，以及原列表/位图/流式精确交集。原有缓存压力启用策略、查询内计数 epoch 失效、延迟激活都保留。候选访问顺序、pSCAN 核心判定和合并规则没有改变。

新上界与缓存共享只改变得到同一布尔相似度答案的方式，不用近似估计，不新增覆盖阈值或用户参数。

## 4. 扫描工作量

Yelp 最终三轮计数一致，且与首轮一致。确定性计数如下（不是唯一边数）：

| 指标 | V13 | 新上界 |
|---|---:|---:|
| 见证计数构建次数 | 19,504,271 | 10,556,276 |
| 见证计数复用次数 | 24,631,030 | 10,492,072 |
| 为新界读取的倒排条目 | 4,348,724,699 | 2,965,495,992 |
| 进入列表/位图/流式交集的调用 | 68,297 | 48,074 |
| 单个见证缺失上界拒绝 | 0 | 6,231,351 |

复用次数下降不代表缓存变差：较早结束后，后续集合既不需要读取也不需要查缓存。总相似度判定请求仍为 8,600,802 次。新上界拒绝数是 `witness_bound_rejects` 的子集，不能再次相加。

扫描量下降不等于总时间同比下降；仍有候选枚举、边证书表、构造计数和分支处理等工作。没有仅凭访问计数就认定当前总时间的主瓶颈已经完全解决。

## 5. 正确性检查

扩展独立全路径集合遍历＋整数相似度直接聚类 oracle。14 个图（新增稀疏见证位图边界用例）、两种对称路径、五种缓存预算、五个 ε、四个 μ。25,200 组聚类比较和 159,543,600 次精确邻域谓词比较通过；位图路径在人工图中实际执行了 28,929 次，并检查保留空间不超过其预算。

## 6. 索引与空间

最终缺失上界只复用 V13 已有见证计数，没有采用位图试验的额外保留空间。当前查询的见证计数工作区与 V13 相同；Yelp 边证书表仍为 150,994,944 B，不把 32 MiB 邻域缓存额度当成整个算法总内存上限。
