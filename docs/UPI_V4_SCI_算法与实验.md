# UPI-v4：EQI、SCI 与 FLI 三路自适应索引

## 1. 新增的 SCI

UPI-v3 的等价类商图（EQI）只能加速闭邻域高度重复的稠密投影。Movies `A-M-D-M-A` 有 10,128 个顶点、352,600 条投影边，却有 7,736 个邻域等价类，无法有效压缩为商图。

UPI-v4 增加精确相似度证书索引（SCI）。离线阶段对每条投影边 `(u,v)` 保存：

- 两个端点；
- 公共闭邻居数 `c(u,v)`；
- 顶点闭邻域度数数组。

边按照临界结构相似度

`c(u,v)^2 / (d(u)d(v))`

精确降序排列。在线给定 `epsilon=p/q` 后，用整数条件

`c(u,v)^2 q^2 >= d(u)d(v)p^2`

二分定位相似边前缀。整个过程不进行邻域生成和邻域交集运算。取得相似边后，继续执行 pSCAN 的核心点判定、核心连通分量合并、非核心挂接和角色判定。

## 2. 紧凑存储

SCI 根据数据规模自动选择 16 位或 32 位端点、度数和公共邻居数字段，并将整个负载连续写入文件。

Movies `A-M-D-M-A`：

| 项目 | 数值 |
|---|---:|
| SCI 离线构建 | 532 ms |
| 未压缩 SCI | 4,271,760 B |
| 紧凑 SCI | 2,135,912 B |
| 完整物化图 | 2,861,324 B |
| SCI / 物化图 | 74.6% |

紧凑布局还将单次索引加载由约 17 ms 降到约 2 ms。

## 3. UPI-v4 自动路由

在线优先级：

1. 存在 EQI：在等价类商图上查询；
2. 否则存在 SCI：读取达到 epsilon 的证书前缀；
3. 否则：使用 FLI 的度分桶与在线相似度验证。

离线 SCI 采用全局预算。默认额外 SCI 空间不超过已有 FLI/EQI 总空间的 100%。候选路径按投影边数从大到小选择；单个 SCI 还必须小于该路径的完整物化图。

## 5. 在线结果

### DBLP `A-P-A`（SCI）

- UPI 内部在线时间：约 0--2 ms；
- 含进程启动和结果写盘，30 次平均：15.66 ms；
- 旧完整流程 5 次平均：89.91 ms；
- 端到端加速：5.74 倍。

### Movies `A-M-D-M-A`（SCI）

- 四组参数的 UPI 内部在线时间：3--5 ms；
- 含进程启动和结果写盘，30 次平均：16.52 ms；
- 旧完整流程 5 次平均：348.86 ms；
- 端到端加速：21.11 倍。

### DBLP `A-P-V-P-A`（EQI）

- 18,275 个顶点和 32,247,867 条投影边压缩为 108 个等价类、3,862 条商图边；
- 旧完整流程：16,286 ms；
- 含启动和写盘的 UPI 查询平均：24.357 ms；
- 端到端加速：668.6 倍。

## 6. 正确性

- DBLP `A-P-A` 八组参数：簇文件和角色文件全部完全一致；
- Movies `A-M-D-M-A` 四组参数：簇文件和角色文件全部完全一致；
- 合计 12/12 组通过；
- DBLP `A-P-V-P-A` 另外四组参数的簇文件与物化后的原版 pSCAN 完全一致。

## 7. 当前结论与边界

UPI-v4 已证明同一个离线索引可以根据路径数据特征选择不同表示：EQI 处理高重复稠密投影，SCI 处理低重复且规模可控的投影，FLI 提供低空间兜底。在线加速范围从普通路径约 5--21 倍，到高度可压缩路径约 669 倍。

当前快速层仍限定为完整长度不超过 6 的非回退对称元路径。下一阶段应先在 IMDB、Yelp 等更大数据上验证构建峰值内存和预算稳定性，再决定是否实现回退型元路径的半增量组合层。
