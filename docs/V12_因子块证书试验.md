# V12：因子块核心证书与候选跳过试验

日期：2026-09-07。研究原型，默认 `bri_query_index` 仍为 V11 执行方式；V12 的入口是 `bri_query_blocks`，输入参数格式相同。没有改变持久索引格式，没有新增 coverage-floor。

本轮结论：Movies 首次查询 201.7 → 159.1 ms，IMDB 3.65 → 2.87 s，Yelp 65.52 → 43.08 s。相对本轮 HINSCAN 完整复现分别为 2.14×、2.73×、2.90×；Yelp 为一次探索测量，其余为三次中位数。尚未达到数量级提升。

## 1. 已实现的最小机制

对半路径见证点 w，其倒排集合 S(w) 中任意两个顶点都至少共享 |S(w)| 个闭邻居。将倒排按闭邻域度数排序，取满足 ε·d(v) ≤ |S(w)| 的前缀 C(w)。实现使用现有 `required_common_neighbors(d,d)` 判据，保持与当前精确阈值实现一致。

对于 u、v ∈ C(w)：

`common(u,v) ≥ |S(w)| ≥ ε·max(d(u),d(v)) ≥ ε·sqrt(d(u)d(v))`。

因此该前缀内的每对不同顶点均相似。如果 |C(w)|−1 ≥ μ，则每个顶点已由**单个块**证明至少具有 μ 个不同相似邻居，可以标记为核心，并以星形连接批量合并。重叠块只做集合标记及并查集合并，不把多个块大小直接相加。

执行顺序可以与 V11 不同，但核心阈值、相似度、核心连通性和非核心归属规则不变，不是换成另一种聚类定义。

## 2. 不漏结果的执行约束

- 已证明核心的顶点使用 μ 作为相似度数下界；有效度数保留原度数上界，不需要逐边初始化其候选数。
- 未证明的顶点仍完整初始化自己的 sd/ed。这里按顶点单独累计自动相似邻居，避免另一端是已跳过核心点时漏掉贡献。
- 只有已证明核心、且处于同一个已证核心连通分量的内部候选可被省略。
- 跨分量核心连接仍精确检查。没有块证明的顶点仍走 pSCAN 的核心判定。
- 非核心归属阶段保留全部可能的核心—非核心关系；只提前过滤已确定的核心邻居，不忽略多簇归属。

## 3. 三种执行方式用于消融

| 模式 | 执行方式 | 入口 |
|---|---|---|
| 对照 | V11 加同口径统计 | `bri_query_index` |
| 仅块证明 | 提前证明核心并合并，剩余候选仍按旧方式展开 | `bri_query_block_seed` |
| 块证明＋跳过 | 在度数有序倒排中直接跳过已证核心块前缀，并提前过滤内部核心候选和最终核心邻居 | `bri_query_blocks` |

三者都是同一套 pSCAN 代码的执行开关，不是三种聚类定义；另保存了改动前的 V11 二进制，作为独立时间对照。开关属于研究消融，没有要求用户输入新的算法参数。

当前实现是**块级前缀跳过＋剩余候选列表**，尚不是逐个拉取全部候选的通用惰性迭代器。连通分量跳过使用块预处理结束时的已证分量，后续合并只会让该过滤保守，不会错误跳过；动态更新分量过滤留待下一步研究。

## 4. 本轮小规模结果

Movies、IMDB 均为 A-M-D-M-A，ε=0.5、μ=5。所有模式都从同一份 BRI 首次构建临时 FLI，包含加载、计算、簇及角色输出和进程退出。串行运行 3 次，取中位数；偶数轮反转模式顺序。操作系统文件缓存没有清空。

| 数据集 | HINSCAN 完整复现 | V11 | 仅块证明 | 块证明＋跳过 | 比 V11 快 | 比 HINSCAN 快 |
|---|---:|---:|---:|---:|---:|---:|
| Movies | 341.207 ms | 201.657 ms | 170.133 ms | 159.125 ms | 1.27× | 2.14× |
| IMDB | 7,848.799 ms | 3,648.417 ms | 3,184.835 ms | 2,871.923 ms | 1.27× | 2.73× |

HINSCAN 指项目中的“重新物化同构图＋未修改的上游 pSCAN”复现，不是官方 HINSCAN 源码。V11 不是读取提前生成的 FLI，而是同样的首次 BRI 查询。新版本的计时范围为 Movies 158.681–181.712 ms、IMDB 2,835.522–3,103.579 ms；不能用最好一轮拼接加速比。

## 5. 工作量确实减少，但还不是数量级

| 指标 | Movies 对照 | Movies 块版本 | IMDB 对照 | IMDB 块版本 |
|---|---:|---:|---:|---:|
| 实际输出候选次数 | 1,536,364 | 868,150 | 25,434,615 | 13,532,756 |
| 实际读取候选倒排条目 | 1,902,544 | 1,475,546 | 37,832,385 | 30,595,591 |
| 精确检查次数 | 140,812 | 117,271 | 2,014,602 | 1,614,346 |

这些是跨阶段累计的实际访问次数，不是唯一投影边数。前缀跳过、度数剪枝、逐条过滤等计数不能简单相加当成唯一边覆盖率。

Movies 发现 284 个可证核心块，覆盖 3,544 个核心点，最终核心点为 5,686 个。IMDB 发现 4,753 个块，覆盖 64,408 个核心点，最终核心点为 83,926 个。覆盖核心点多，不代表全部跨块工作也消失：IMDB 仍有约 161 万次精确判断。

IMDB 第二轮块发现约 2.932 ms，核心阶段约 2,236.790 ms，非核心阶段约 90.382 ms；同轮对照核心阶段约 2,803.480 ms，非核心阶段约 375.900 ms。块发现计入剪枝阶段，不应重复计入总时间。

## 6. 索引与内存边界

- 离线依旧只输入 HIN 和 schema，输出同一份 BRI；在线才使用元路径、ε、μ生成本次块证书。
- 不持久保存各元路径投影图、类图或全量相似度。每次查询后证书与临时 FLI 都释放。
- Movies 的持久 BRI 为 997,364 B，IMDB 为 7,982,439 B，与 V11 相同。
- 新增块工作区分别为 Movies 59,632 B、IMDB 546,948 B，包括每顶点初始核心分量标记和每见证点前缀长度；复用原并查集，没有构建完整的块间图。
- 邻域及因子对缓存总额度仍为 32 MiB，但这不是总内存上限。IMDB 在线边证书表仍为 37,748,736 B，不能因为检查次数下降就宣称其分配容量同步下降。

## 7. 正确性与复现

独立全路径集合遍历与直接聚类参考，覆盖 13 个确定性/随机图、两种元路径、五个 ε、四个 μ、五种缓存预算、四种执行组合。新增两个块之间的桥接、重复见证点、重叠块链，防止漏跨块连接或重复计数。共 23,948,640 次精确谓词和 10,400 组聚类比较通过。

真实参数矩阵 18 组的簇和角色全部与 V11 精确参考逐字节一致，包含不同元路径及 ε=0.2–0.9。主时间实验还重新运行上游 pSCAN，簇文件逐字节一致；角色文件与 V11 对照。上游 pSCAN 本身不输出本项目格式的角色文件。

```powershell
build-cmake/bin/bri_query_blocks.exe experiments/v11/benchmark/imdb_legacy/base.bri A-M-D-M-A 0.5 5 experiments/v12/demo
build-cmake/bin/verify_adaptive_fli.exe experiments/v12/fixtures
experiments/validate_v12.ps1
experiments/benchmark_v12.ps1 -IncludeHinBaseline
experiments/benchmark_v12.ps1 -Datasets yelp -Repeats 1 -IncludeHinBaseline
```

原始日志位于 `experiments/v12/benchmark/`，汇总为 `experiments/v12/summary-*.csv`，正确性记录为 `correctness.log` 和 `real-correctness.csv`。

## 8. Yelp 扩展试验

U-R-B-R-U，ε=0.9、μ=5。本轮重新物化图并运行上游 pSCAN，各模式串行测一次，输出均一致。

| 模式 | 完整在线时间 |
|---|---:|
| HINSCAN 完整复现 | 124,993.078 ms |
| 保存的 V11 二进制 | 65,518.630 ms |
| 当前代码关闭块模式 | 65,867.771 ms |
| 仅块证明 | 52,264.453 ms |
| 块证明＋候选跳过 | 43,076.166 ms |

相对 V11 为 1.52×，相对 HINSCAN 为 2.90×。不能将这一参数上的单次结果推广为所有 Yelp 查询的稳定加速比。

| 工作量 | 关闭块模式 | 块证明＋跳过 |
|---|---:|---:|
| 累计输出候选次数 | 395,875,485 | 63,446,549 |
| 候选倒排读取条目 | 402,211,349 | 80,408,708 |
| 精确判断次数 | 10,359,646 | 8,600,802 |

块模式发现 9,633 个可证核心块，覆盖 388,302 个核心点，占最终 414,719 个核心点的约 93.6%。新增块工作区为 2,216,556 B。按前缀直接跳过 211,462,800 次条目访问；这仍是跨阶段累计量，不是唯一边数。

块发现 18.254 ms，临时 FLI 构建 867.384 ms，核心阶段 38,662.300 ms，非核心阶段 1,287.530 ms。完整核心阶段仍然很重：候选输出减少约 6.24 倍，但精确判断只减少约 17%，故总时间没有同步减少 6 倍。下一瓶颈是剩余跨块相似性判断及证书处理，而非重新构建整张同构图。

仅证明核心和最终模式的精确判断次数相同，二者时间差主要来自候选跳过、提前过滤和不必要邻域激活的减少。这也是为什么需要分别保留两个消融模式。

| IMDB | 207.843 ms | 7,982,439 B |

复现离线测量：`experiments/measure_v12_offline.ps1`。记录为 `experiments/v12/offline-times.csv`、`offline-summary.csv`。源文件与二进制哈希见 `experiments/v12/build-manifest.csv`。
