# FLI-0 实现说明

## 当前范围

FLI-0 是 non-independent HINSCAN 的精确离线原型，支持由类型序列定义的对称元路径。它不保存元路径投影图的邻接边，而保存：

- `W[u]`：目标顶点 `u` 到中心类型的半路径见证集合；
- `L[x]`：中心见证 `x` 对应的目标顶点倒排表；
- `degree[u]`：投影图中包含自身的精确结构邻域大小。

对于对称元路径 `P=P_L P_L^{-1}`：

```text
N_P[u] = {u} union (union over x in W[u] of L[x])
```

构建过程中只临时合并单个顶点的倒排表计算度数，不保存完整 `N_P[u]`。

## 索引上的 pSCAN 查询流程

1. 使用时间戳数组合并 `W[u]` 对应的倒排表，只暂存当前 `u` 的结构邻域。
2. 每个无向候选只在较小端点处处理一次。
3. 先执行精确度数比例剪枝。
4. 维护 pSCAN 的相似度数 `sd` 和有效度数 `ed`，先处理已证明为核心的顶点，否则处理 `ed` 最大的顶点。
5. 只在 `sd < mu <= ed` 时继续精化未知边，不必判定所有 noncore--noncore 点对。
6. 对必须精化的点对，用时间戳数组扫描右端倒排表；交集达阈值时提前接受，剩余项全部命中也不足时提前拒绝。
7. 使用并查集合并相似的 core--core 边；核心簇完成后，再精化 core--noncore 边并挂载非核心点。
8. 查询内只缓存已做过精确判定的稀疏边证书，不保存完整投影邻接表。

当前时间戳工作区使用三个 `uint32_t` 数组，空间为 `12 * |V_A|` 字节；候选邻域在处理完一个顶点后立即释放。`FliScan.cpp` 保留为全候选验证版，正式在线执行位于 `PscanOnFli.cpp`。

`pscan_on_fli` 还支持可选的有界 LRU 邻域缓存。缓存为 0 MiB 时是纯免物化模式；给定正预算时，它只在预算内保留热点顶点的完整邻域，构成半离线/半增量模式。缓存统计单独报告 payload 峰值。精确相似度证书使用专用开放寻址表，避免通用 `unordered_map` 的逐节点开销。

## `.fli` 文件

版本 1 的离线文件包含：

- 格式魔数、版本、字节序和整数宽度；
- 目标顶点数、中心顶点数和统计信息；
- `W` 排序列表；
- `L` 排序列表；
- 精确结构度数。

加载时检查魔数、版本、端点范围、列表严格有序性、半路径关联总数、度数范围和文件尾。当前格式使用本机小端整数，尚未压缩，也尚未加入数据源指纹和元路径文本元数据。

## 正确性不变量

- 元路径必须是对称类型序列。
- 每个 `W[u]` 和 `L[x]` 严格有序且无重复。
- `W` 与 `L` 的关联总数相同。
- 惰性/时间戳合并得到的邻域必须包含自身。
- 每条候选无向边只处理一次。
- 度数比例剪枝、提前接受和提前拒绝均只使用安全界。
- 聚类输出采用每个核心连通分量的最小核心顶点作为簇 ID，因此可与 pSCAN 直接逐字节比较。

## 尚未实现

- 分块交集上界；
- 基于访问频次/倒排扫描收益的自适应缓存选择；
- 跨 epsilon 复用的精确交集证书；
- Roaring Bitmap、压缩 CSR 或内存映射索引；
- 数据更新、支持计数和证书失效；
- entity/relation 格式转换器。
