# UPI V6：多覆盖层 SECI

> 后续的 T-SECI 已用“单文件+按阈值读取证书前缀”取代多文件层。本文保留为中间方案和对照实验记录。

## 1. 动机

单层 SECI 存在覆盖范围和加载速度之间的直接冲突。较低覆盖下界能够回答更多 epsilon，但证书文件更大；高 epsilon 查询虽然只使用其中很短的证书前缀，仍必须读取整个低阈值文件。

多覆盖层为同一条元路径保存若干嵌套的 SECI 文件。例如0.3层覆盖所有 `epsilon >= 0.3` 的查询，0.9层只覆盖 `epsilon >= 0.9`，但体积远小于0.3层。在线选择不超过查询 epsilon 的最高可用层。

## 2. 一次计算派生多层

离线构建只在最低覆盖下界执行一次完整工作：

1. 从 FLI 生成闭邻域等价类。
2. 构建商图并计算最低覆盖下界所需的精确类证书。
3. 按临界结构相似度对证书降序排列。
4. 对每个更高覆盖下界执行一次二分，复制对应证书前缀并写成连续存储v2文件。

因此0.5、0.7和0.9层不会重复计算闭邻域、商图或公共邻居。额外成本主要是前缀复制和顺序写文件。

## 3. 空间预算策略

所有 SECI 层和 SCI 共用 `certificate-budget-percent`。路径仍按投影边数从大到小处理；一条稠密路径的候选层按覆盖下界从高到低尝试保存：

- 高覆盖层更小，优先保证高 epsilon 查询的低延迟。
- 某层超过剩余预算时只跳过该层，不影响更小层。
- 如果该路径至少保留一个 SECI 层，就不再重复保存完整 SCI。
- 查询未被任何层覆盖时回退 FLI。

该策略不会改变结果，只改变可用的快速路径。

## 4. 文件和路由

UPI manifest 升级为版本5，记录全局候选覆盖层。SECI 文件名包含约分后的覆盖分数，例如：

- `0-1-2.seci-3-10`
- `0-1-2.seci-1-2`
- `0-1-2.seci-7-10`
- `0-1-2.seci-9-10`

查询程序逐层检查该元路径实际存在的文件，并选择满足 `floor <= epsilon` 的最大 floor。加载器继续兼容UPI manifest版本1--4和SECI格式v1。

## 5. Movies 实验

配置：最大半路径长度2，辅助索引预算100%，覆盖候选层 `0.3,0.5,0.7,0.9`。

完整UPI包含12条路径，保存11个SECI层和1个SCI，总大小12,491,129字节，构建1.373秒。目标路径 `A-M-D-M-A` 的四层为：

| 覆盖下界 | 文件大小 |
|---:|---:|
| 0.3 | 2,159,660 B |
| 0.5 | 621,620 B |
| 0.7 | 220,328 B |
| 0.9 | 115,292 B |

`epsilon=0.3/0.5/0.7/0.9` 分别选择对应层，簇和角色全部与精确基线一致。`epsilon=0.8` 选择0.7层并在层内二分，结果与原pSCAN一致；`epsilon=0.2` 低于全部层，正确回退FLI。

## 6. IMDB 预算实验

相同配置下，完整UPI保存13个SECI层和1个SCI，总大小76,305,547字节，构建24.109秒。目标路径 `A-M-D-M-A` 的预算选择为：

| 覆盖下界 | 是否保存 | 文件大小 | 单次内部加载 |
|---:|---|---:|---:|
| 0.3 | 否 | 估计34.38 MB | -- |
| 0.5 | 是 | 8,559,584 B | 4 ms |
| 0.7 | 是 | 1,883,528 B | 2 ms |
| 0.9 | 是 | 866,120 B | 1 ms |

0.3层因超过剩余预算被跳过，因此0.3查询回退FLI；其余三个参数自动选择对应层，结果均与原pSCAN一致。

| epsilon, mu | 路由 | 20次端到端平均 | 中位数 |
|---|---|---:|---:|
| 0.5, 5 | SECI 0.5层 | 49.06 ms | 47.16 ms |
| 0.7, 5 | SECI 0.7层 | 46.32 ms | 45.10 ms |
| 0.9, 2 | SECI 0.9层 | 37.30 ms | 35.91 ms |

使用单一0.5层回答0.9查询时平均40.68毫秒；专用0.9层降为37.30毫秒。端到端收益受簇和角色文件写出限制，但内部加载从4毫秒降到1毫秒。若在线API直接返回内存结果或只返回统计，层选择收益会更明显。

## 7. 当前结论

多覆盖层验证了三点：

1. 可以从一次最低层构建精确派生所有高层，不重复相似度计算。
2. 空间预算能够自动保留多个小型高层并舍弃过大的低层。
3. 任意层内epsilon、层间epsilon和低于全部层的查询都保持精确。

下一步应研究共享等价类成员区，使多个层只保存一次类成员和度数，各层文件仅保存不同长度的证书前缀；这能消除当前多层之间约0.8 MB至数 MB的重复元数据。
